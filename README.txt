Carbon Footprint Awareness Platform - Web Technology Project

HOW TO RUN: unzip, then double-click login.html (or open with Live Server). Internet is needed for Chart.js, jsPDF and Google Fonts.
FIRST TIME: click "Sign Up", create an account, then log in.

VALIDATION RULES
- Email must look like name@example.com
- Phone must be exactly 10 digits (letters/symbols are blocked while typing)
- Password minimum 6 characters

PAGES: login.html, index.html (Home), calculator.html, learn.html (info + quiz), about.html
FILES: css/style.css, js/auth.js, js/calculator.js
